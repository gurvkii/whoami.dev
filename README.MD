# Whoami.Dev
This project serves as a collection of fun things that I wanna build as time passes.
For the starting I have built (Digital Cemetery),
A graveyard where you can bury your ideas or anything you want! and all the data is saved in localstorage so don't worry that I can see it or not !,

### Tech Stack 
The project uses HTML, CSS AND JS for the fronted ( backend is not implemented yet ) and the Data is stored on the broswer's localstorage.

### Screenshots 

### Why I build it?
I just wanted a collection of fun things at one place so I build this as for now there is only 1 feature but as time passes I am planning to add more features as well.

### features 
- Hard coded Auth system ( whoami.dev is the password, email can be anything !)
- Spooky Background music ( To scare you )
- Custom hand drawn assets for personal touch 
- Supports both light and dark mode 
- Local storage for storing data 


### How to run 
You can either clone the repo and launch index.html on the root folder 
OR 
You can click on the given demo URL : https://gruvkii.github.io/whoami.dev/pages/login_signup/auth.html
